DESIGN STYLE

The website should feel:

Modern

Premium

Dynamic

Easy to navigate

Avoid making the website look like a generic template.

It should feel like a professionally designed website for a real modern driving school.

SCROLL ANIMATIONS

This is one of the most important requirements.

The website should have a high-quality scrolling experience.

As the user scrolls down the page, individual sections should smoothly animate into view.

Use subtle animations such as:

fade-in

slide-up

slide-left

slide-right

scale-in

staggered card animations

subtle image movement

parallax effects where appropriate

For example:

When a section enters the viewport:

heading fades in

text slides up

image smoothly appears

cards appear one after another with a small delay

Cards should use staggered animations such as:

Card 1 → 0ms
Card 2 → 100ms
Card 3 → 200ms
Card 4 → 300ms

Animations should feel smooth and premium, not flashy or distracting.

Use Intersection Observer or an appropriate animation library.

Make sure animations are performant and do not cause unnecessary layout shifts.

Also respect prefers-reduced-motion for accessibility.

Primary CTA button

subtle shadow

Navigation links should smoothly scroll to the corresponding sections.

On mobile:

use a hamburger menu

animate the mobile menu opening/closing

make the navigation easy to use with touch
